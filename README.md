# もぐら珈琲研究所（架空のお店のデモサイト）

https://nc16152.github.io/mogura-coffee-lab/

**Claude Code** に「適当な会社の、適当な事業のサイトを作って公開して」と頼んで作ったデモです。
会社名・住所・商品・価格・数字はすべて架空で、実在のものとは関係ありません。

## 入っているもの

- 1枚のページ（`index.html` / `style.css` / `script.js`）。ビルドの道具は使っていません
- 絵はすべてコードで描いた SVG（写真・画像素材なし）
- 動くところ
  - 豆のラインナップを焙煎度で絞り込み
  - 定期便の月額シミュレーター（量・間隔・挽き方 → ひと月の金額・送料・1杯あたり）
  - よくある質問の開閉、スマホ用のメニュー、スクロールで出てくるアニメーション
  - お問い合わせ欄は **どこにも送信しません**（押すと入力内容を消すだけ）
- 公開は GitHub Pages（このリポジトリの `main` ブランチをそのまま配信）
